Local end-to-end scenarios

These saved scenarios are a browser acceptance plan, not evidence that every interaction has run. The release owner executes them through Cua against the deployed local system at desktop, tablet and phone widths. Rendered React tests run separately via npm run test:components; Node behavior tests via npm test.

Use newly owned local QA fixtures, keep credentials only in memory, and capture settled states. Fault injection must be limited to the controlled local QA proxy or test adapters. No public photo/recipe mutation, unrelated accounts, actual internet publication, or agent-triggered OS permissions. Creator publication remains disabled outside the explicitly isolated QA fixture.

Record actual case and viewport outcome, observed API status and proof path in the release evidence. Delete only newly owned QA rows and restore temporary owned flags. A saved scenario is not a production certification or a complete accessibility audit.
